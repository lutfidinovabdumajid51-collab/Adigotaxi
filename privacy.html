Privacy Policy for Adigo Taxi

Last updated: February 2026

Adigo Taxi (“we”, “our”, or “us”) respects your privacy and is committed to protecting your personal data. This Privacy Policy explains how we collect, use, store, and protect information when you use the Adigo Taxi mobile application.

1. Information We Collect

Personal Information

  • Phone Number – used for user authentication via SMS (Firebase Authentication). Supported regions include Uzbekistan (+998) and South Korea (+82).

Location Information

  • Approximate location
  • Precise location

Location data is used to determine pickup and drop-off points, calculate distance and pricing, and match passengers with nearby drivers.

Order Information

  • Pickup and destination locations
  • Route details
  • Service type
  • Passenger count
  • Order notes, time, and price

App & Device Information

  • Firebase device identifiers
  • Crash logs and diagnostics
  • App interaction data (order creation, acceptance, cancellation)

Push Notifications

  • Firebase Cloud Messaging (FCM) token – used to send order status and service notifications

2. How We Use Information

  • User authentication and account management
  • Order creation and processing
  • Driver matching and dispatching
  • Service-related notifications
  • Fraud prevention, abuse detection, and security
  • App performance monitoring and crash analysis
We do NOT use personal data for advertising or marketing purposes.

3. Telegram Integration

For operational purposes, order details may be forwarded to a private, driver-only Telegram group.

  • Phone numbers are not shared publicly
  • A passenger’s phone number is visible only after a driver accepts an order
  • Telegram is used strictly for order dispatch and communication support

4. Data Storage & Security

  • All data is stored securely on Google Firebase servers
  • Access is restricted to authorized systems only
  • All data is encrypted in transit using HTTPS/TLS

5. Third-Party Services

  • Firebase Authentication
  • Firebase Realtime Database
  • Firebase Cloud Messaging (FCM)
  • Firebase Crashlytics
  • Google Play Integrity API
  • Google reCAPTCHA

6. Data Retention

User data is retained only as long as necessary to provide the service and comply with legal or security obligations.

  • Most user data is deleted immediately after account deletion
  • Some technical or security-related data may be retained for up to 30 days

7. Children’s Privacy

Adigo Taxi is not intended for children under the age of 13. We do not knowingly collect personal data from children.

8. Policy Updates

We may update this Privacy Policy from time to time. Any changes will be published on this page with an updated revision date.

Authentication Methods - Adigo Taxi

Authentication Methods

Users can sign in to the Adigo Taxi application using the following methods:

  • Phone number with SMS verification
  • Telegram login

Phone Number Authentication

Phone numbers are collected and used only for:

  • User authentication
  • Order-related communication (ride confirmations, updates, support)

Phone numbers are not used for advertising or marketing purposes.

Telegram Login

Telegram login is available as an alternative authentication method.

When users sign in using Telegram:

  • Only the Telegram User ID is collected and stored
  • We do not access Telegram messages, contacts, phone numbers, or media
  • We do not read or store private chats
  • No messages are sent without user interaction

Telegram data is used strictly for authentication and security purposes.

9. Delete Account & Data

Users may request deletion of their account and associated personal data at any time.

How to request account deletion:

  1. Email us at adigotaxi@gmail.com
  2. Use subject: Delete My Adigo Taxi Account
  3. Include the phone number used to register in the app

Upon deletion, we will remove:

  • Phone number
  • Order history
  • Associated Firebase identifiers

Some data may be retained for up to 30 days for legal or security purposes.
