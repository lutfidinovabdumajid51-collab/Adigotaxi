Privacy Policy — Adigo Taxi

Last updated: 2026

Adigo Taxi (“we”, “our”, or “us”) operates the Adigo Taxi mobile application and related services. This Privacy Policy explains how we collect, use, store, and protect user information when you use our application.

1. Information We Collect

Personal Information

- Phone number (for authentication and communication)
- User name (optional)
- Telegram User ID (if Telegram login is used)

Location Information

Pickup and destination locations and real-time location during active orders. Location data is used only for providing ride services.

Technical Information

Device type, operating system, app version, Firebase identifiers, notification tokens, and crash data.

2. How We Use Information

We use collected information to provide taxi services, authenticate users, connect passengers with drivers, send order notifications, improve performance, and prevent fraud.

We do not sell or rent personal data.

3. Authentication Methods

Phone Number Authentication

Phone numbers are used only for login verification and order communication. They are not used for advertising or marketing.

Telegram Login

Only Telegram User ID is stored. We do not access messages, contacts, or media. Telegram data is used only for authentication and security.

4. Notifications

Adigo Taxi uses push notifications for order updates, driver arrival information, and important service announcements.

5. Data Sharing

Information may be shared only when necessary with drivers, Firebase (Google services), or when required by law.

6. Data Retention

User data is retained only as long as necessary. Most data is deleted after account deletion. Some technical data may be retained for up to 30 days.

7. Children’s Privacy

Adigo Taxi is not intended for children under 13 years of age.

8. Security

We use industry-standard security measures including Firebase authentication and database security rules.

9. Account and Data Deletion

Users may request account deletion by emailing:

Email: adigotaxi@gmail.com

Subject: Delete My Adigo Taxi Account

After deletion, phone number, order history, and Firebase identifiers will be removed. Some data may be retained for up to 30 days for legal or security purposes.

10. Policy Updates

We may update this Privacy Policy from time to time. Changes will be published on this page.

11. Contact Us
