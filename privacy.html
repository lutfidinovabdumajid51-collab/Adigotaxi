Privacy Policy for Adigo Taxi

Last updated: February 2026

Adigo Taxi (“we”, “our”, or “us”) respects your privacy and is committed to protecting your personal information. This Privacy Policy explains how we collect, use, store, and protect information when you use our mobile application.

1. Information We Collect

Phone Number: Used for SMS authentication via Firebase (Uzbekistan +998, South Korea +82).

Location Data: Used to determine pickup location, calculate distance and pricing, and match drivers.

Order Information: Route details, service type, passenger count, notes, time, and price.

Technical Data: Firebase device identifiers, crash logs, and diagnostics.

Push Notifications: FCM token for order updates.

2. How We Use Information

  • User authentication
  • Order processing
  • Driver matching
  • Notifications
  • Security and abuse prevention

We do not use personal data for advertising.

3. Telegram Integration

Orders may be sent to a private Telegram driver group. Phone numbers are shared only after order acceptance.

4. Data Storage & Security

Data is securely stored on Google Firebase servers with strict access control.

5. Third-Party Services

  • Firebase Authentication
  • Firebase Realtime Database
  • Firebase Cloud Messaging
  • Google Play Integrity API
  • reCAPTCHA

6. Data Retention

Data is stored only as long as necessary. Users may request deletion via email.

7. Children’s Privacy

This app is not intended for children under 13.
